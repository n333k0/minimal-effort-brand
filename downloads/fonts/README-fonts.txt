Minimal Effort typefaces

1. ABC Normal (Heavy for display, Medium for sub-heads) — Dinamo, commercial.
   Licence it at https://abcdinamo.com/typefaces/normal before use. Not included in this kit.
   If it is not available, the fallback for drafts is Helvetica Neue Bold with -3% tracking.
2. Manrope (400-800) — text, web, captions. SIL Open Font Licence, included.
3. IBM Plex Mono (400, 500) — labels, dates, venues, signatures. SIL Open Font Licence, included.
   It stands in for Decima Mono, which the original identity deck used.
